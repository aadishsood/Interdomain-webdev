Inside the
System

Every module of PAPR, from seeing to gripping, works as one connected pipeline.

01

Camera & Vision

High-frame-rate camera captures live views for real-time shape, structure, and position analysis using custom CNN inference.

  • 120 FPS global shutter
  • 640×480 ROI processing
  • ONNX Runtime inference
02

Sensors

Multi-modal sensing for object presence detection and fine position feedback along the pick and place trajectory.

  • Time-of-flight proximity
  • Force/torque at wrist
  • Encoder feedback per joint
03

Robotic Arm

6-DOF articulated arm with harmonic drives for precise, repeatable motion in confined workspaces.

  • Reach: 850 mm
  • Repeatability: ±0.05 mm
  • Max speed: 3 m/s TCP
04

Adaptive Gripper

Underactuated 3-finger gripper with compliant joints that auto-adapts to object geometry without explicit grasp planning.

  • Stroke: 40 mm per finger
  • Grasp force: 0.5–15 N
  • Tactile pads on fingertips
05

Conveyor System

Synchronized belt conveyor with encoder feedback for precise object presentation to vision and pick zones.

  • Speed: 0–500 mm/s
  • Position accuracy: ±1 mm
  • Zone-triggered indexing
06

Central Controller

Real-time Linux controller running ROS 2, coordinating vision inference, trajectory planning, and motion execution.

  • Intel NUC i7 / RPi 5
  • ROS 2 Humble / RT kernel
  • EtherCAT for I/O

Complexity is
a Design Brief

We start by naming the friction in robotic automation, then turn it into a system operators can navigate with confidence.

When perception, planning, and control work in isolation, critical signals get lost in translation. PAPR makes the invisible handoffs visible.

01

Unify Perception & Action

Shared state bus connects vision output directly to motion planner — no intermediate serialization, no latency-inducing middleware.

02

Close the Loop at 200 Hz

Force/torque and vision feedback fused in real-time controller enables reactive adjustment during grasp and place phases.

03

Design for Changeover

Modular gripper fingers, swappable vision models, and parameterized trajectories enable < 5 min product changeover.
